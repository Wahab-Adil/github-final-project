# github-final-project

## Simple Interest Calculator

This repository contains a Bash script that calculates simple interest. It
prompts for the principal amount, annual interest rate, and time period in
years, then displays the calculated interest.

The formula is:

```text
Simple Interest = (Principal x Rate x Time) / 100
```

For example, a principal of 1000 at 5% for 2 years earns 100 in simple
interest.

Run the calculator with Bash:

```bash
bash simple-interest.sh
```
